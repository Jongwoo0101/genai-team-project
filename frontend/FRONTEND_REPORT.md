# 🖥️ WorkSight 프론트엔드 작업 현황 및 협업 가이드

본 문서는 프론트엔드(`frontend`) 브랜치에서 진행된 주요 작업 내용과 백엔드(`backend`) 팀과의 원활한 연동을 위한 요청 사항을 정리한 리포트입니다.

## ✅ 완료된 주요 작업 (Current Status)

### 1. 인증 시스템 (Authentication)
- **실제 API 연동**: `authStore.ts`를 통해 백엔드 `/api/members/login`, `/api/members/signup` 엔드포인트와 연동 완료.
- **역할 기반 라우팅**: 로그인 시 반환되는 `Role`에 따라 관리자 대시보드와 직원 모니터링 화면으로 자동 분기 처리.
- **보안 설정**: Vite 프록시 설정을 통해 CORS 문제를 해결하고 모든 `/api/**` 요청을 백엔드 서버(8080)로 전달.

### 2. 실시간 모니터링 시스템 (Monitoring)
- **이벤트 보고**: 직원 화면(`EmployeeView`)에서 상태 변화 감지 시 `/api/monitoring/event`로 즉시 데이터 전송 로직 구현.
- **실시간 알림 수신**: 관리자 대시보드에서 `SockJS` & `StompJS`를 이용해 서버의 `/topic/alerts` 채널 구독 완료.
- **UI 최적화**: 레이아웃 붕괴 현상을 수정하고, 고해상도 모니터에서도 안정적으로 정렬되도록 디자인 시스템 보강.

## 🚀 백엔드 협업 요청 사항 (Backend Action Items)

### 1. [중요] 회원가입 아이디 중복 체크 로직 추가
- **현상**: 현재 동일한 아이디로 여러 명(또는 여러 역할)이 가입되는 현상이 있습니다. 이 경우 로그인 시 서버에서 `403 Forbidden`을 반환하며 계정이 잠깁니다.
- **요청**: `Member` 엔티티의 `username`에 `unique=true` 제약 조건을 추가하고, 가입 전 중복 여부를 체크하여 에러를 반환해 주세요.

### 2. [추가] 대시보드 조회용 API 구현
- **요청**: 현재 프론트엔드는 통계 및 과거 이력 조회를 위해 아래 엔드포인트를 호출하도록 설계되어 있습니다. 구현 시 참고 부탁드립니다.
  - `GET /api/monitoring/stats`: 전체 직원 수, 온라인 상태, 총 이상 감지 횟수 등 집계 데이터
  - `GET /api/monitoring/events`: 과거에 발생한 이상 상태 이벤트 로그 리스트

### 3. [참고] 웹소켓 폴리필 설정
- 프론트엔드에서 `SockJS` 사용을 위해 `index.html`에 `global` 객체 폴리필을 추가해 두었습니다. 브라우저 호환성 테스트 시 참고하세요.
