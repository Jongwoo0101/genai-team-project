# 직원 업무 태도 모니터링 시스템 기획서

**프로젝트명:** WorkSight AI
**프론트엔드:** React + Vite
**백엔드:** Java Spring Boot (Gradle)
**AI 모듈:** Python (OpenCV, PyTorch/TensorFlow)

---

# 1. 프로젝트 개요

## 1-1. 프로젝트 목적

기존 CCTV 기반의 수동적 직원 감시 시스템의 한계를 보완하기 위해,
직원 개인 PC에 연결된 웹캠을 활용하여 AI가 실시간으로 얼굴 및 자세를 분석하고 업무 태도를 자동 판단하는 시스템을 개발한다.

근무 태만으로 판단되는 행동이 탐지될 경우,
해당 이벤트 전후 일정 시간의 영상을 서버에 자동 업로드하여 관리자에게 전달한다.

---

## 1-2. 개발 배경

기존 방식의 문제점:

* CCTV는 사각지대 존재
* 관리자가 직접 모니터링 필요
* 이벤트 발생 순간 포착 어려움
* 업무 태도 정량적 분석 불가

개선 방향:

* AI 기반 자동 판단
* 이벤트 중심 기록
* 관리자 즉시 알림
* 행동 패턴 데이터화
