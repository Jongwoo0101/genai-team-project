<수정1>
주제: 비대면 근무 관리
1. 사용자 로그인 후 "출근" 버튼을 누르면 출근 시간이 로그에 기록됨, 관리자에게 출근 알람이 간다.
2. "퇴근" 버튼을 누르명 퇴근 시간이 로그에 기록되며,
다음날 아침 관리자가 로그인 하면 관리자에게 이전 날 직원이 퇴근을 몇 시에 했는지 알 수 있음.
3. 자리비움: 자리를 비웠을 경우 자리비움 표시, 자리비움 20분이 지나면 관리자에게 알림, 점심시간은 자동으로 제외.
4. 출근 현황판: 현재 접속중인 인원과 미접속 인원을 차트로 시각화
5. 로그 시점에 접속한 IP 주소를 함께 저장하여 집이 아닌 곳에서 접속했는지 체크

<수정2>
주제: 비대면 근무 관리
1. 출근: '업무 시작' 클릭 시 팀 전체에 온라인 상태 아이콘 공유, 로그에 몇시에 출근했는지 기록
2. 퇴근: '업무 종료' 클릭 시 팀 전체에 오프라인 상태 아이콘 공유, 로그에 몇시에 퇴근했는지 기록
3. 자리비움: 직원 스스로 현재 상태 설정 (집중 근무, 회의, 휴식 등)
4. 현황판: 순 인원 차트 시각화	팀원 상태 기반의 실시간 협업 가능 대시보드
5. 하루끝: 데일리 스탠드업(오늘의 목표/결과) 공유
